# Правила для AI-агентов

## Назначение

Репозиторий хранит OpenTofu modules, policy checks и тесты инфраструктуры Portable Agent.

## Границы

- не добавляй бизнес-код сервисов;
- не храни секреты, токены, state и настоящие данные;
- не создавай production-ресурсы до отдельного ADR и threat model;
- первый тест модуля не должен требовать облачный аккаунт;
- новая технология сначала получает тест и ADR.

## Структура

- `modules/` — маленькие переиспользуемые OpenTofu modules;
- `scripts/` — короткие проверки;
- `docs/` — русская документация;
- `.github/workflows/` — CI.

## Команды

```powershell
pwsh ./scripts/check-tofu.ps1
pwsh ./scripts/check-docs.ps1
```

## Правила изменений

1. Сначала добавь ожидаемое поведение в `*.tftest.hcl`.
2. Добавь минимальный HCL для зелёного теста.
3. Используй простые имена: `name`, `local`, `network`, `project`.
4. Один pull request меняет один инфраструктурный сценарий.
5. Обновляй README и docs вместе с командами.
6. Не добавляй cloud provider, пока задача не требует реального ресурса.
