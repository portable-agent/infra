# Разработка

Работа идёт по TDD:

1. Добавить или изменить assert в `*.tftest.hcl`.
2. Увидеть ожидаемую ошибку.
3. Добавить минимальный HCL.
4. Запустить `pwsh ./scripts/check-tofu.ps1`.
5. Обновить документацию, если изменились границы модуля.

State, `.terraform` и секреты запрещено добавлять в Git.
