# ADR 0001: отдельный infra-репозиторий

- Статус: принято
- Дата: 2026-08-29

## Контекст

OpenTofu state, modules и инфраструктурные проверки имеют другой жизненный цикл, чем Helm charts и код
сервисов.

## Решение

Хранить OpenTofu modules в отдельном репозитории `portable-agent/infra`. Каждый модуль получает test до
добавления реального provider. Первый модуль не требует cloud credentials.

## Последствия

- инфраструктура тестируется отдельно от приложений;
- state и секреты не попадают в Git;
- `deploy` не создаёт cloud-ресурсы;
- выбор provider откладывается до измеримой задачи.
