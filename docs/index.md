# Portable Agent Infra

Этот репозиторий отвечает только за проверяемое описание инфраструктуры. Helm и Kubernetes-доставка
находятся в отдельном репозитории `deploy`.

Сейчас готов один модуль без внешних provider: `modules/name`. Следующий пакет будет выбран только после
успешного CI и ревью текущего пакета.
